# Xbox One backplate + Elite paddles

Parametric mod of `src/Xbox_One_Backplate_Electronic.stl` so original Elite paddles (P1–P4) and 4 glued
6×6 tact switches fit. Faceplate is untouched. Outputs are generated, never edited by hand.

## Layout

| Path | What |
|---|---|
| `src/` | Inputs: base backplate, faceplate, `paddles/paddle1-4.stl` (L+R pair per file, print layout, reference only) |
| `tools/build_backplate.py` | Generates the modified backplate. **All tuning lives in the parameter block at the top.** |
| `tools/make_coupon.py` | Cuts the paddle panel (66×20 mm) out of the output for a quick fit-test print |
| `output/` | `…_Elite_Paddles.stl` (full part) and `…_TEST_COUPON.stl` — regenerated by the scripts |
| `ref/third_party/` | Unrelated downloaded packs (`stl/`, `Electronic Pattern/`, `designs/`) — local only, git-ignored |

## Regenerate

From the project root (no Python install needed, uses `uv`):

```
uv run --with numpy --with trimesh --with scipy --with networkx --with rtree --with manifold3d --with shapely --with mapbox-earcut python tools/build_backplate.py
uv run --with numpy --with trimesh --with scipy --with networkx --with rtree --with manifold3d python tools/make_coupon.py
```

Expect `watertight: True` and `delta vs source: -62.7` (volume mm³) for the current parameters.

## Geometry (model coordinates, mm)

Exterior = +Z, panel centre line X = 30.5, paddle rows at Y = 15.8 / 23.5. Left/right are mirrored about X = 30.5.

- **Hook opening:** straight rectangle 4×6 (+0.25 clearance per side) with a centred 2×2 slit towards the button.
  Inside face: chamfered retaining ramp block (leaves the slit band clear).
- **Button hole:** Ø3.9 (+0.5), 1 mm wall from the slit tip. 6×6 tact switch is glued inside the 3-sided frame
  (open side faces the hook opening); plunger passes through the hole.
- **Magnets (8×3):** pockets **removed** — glued on by hand. Code kept (`MAG_Y = ()`).

Key parameters:

| Parameter | Now | Meaning |
|---|---|---|
| `HOOK_DX` | 18.55 | Opening centre distance from the centre line. Button position is derived from it (`BTN_DX` = 26.25) |
| `OPEN_W, OPEN_L` / `CLEAR` | 4.0, 6.0 / 0.25 | Caliper-measured opening and print tolerance |
| `NOTCH_L, NOTCH_H` | 2.0, 2.0 | Slit towards the button |
| `BLK_W, RAMP_H, RAMP_TIP` | 2.0, 2.4, 0.5 | Retaining ramp block |
| `SW_SIZE, SW_CLEAR, SW_WALL, SW_DEPTH` | 6.0, 0.3, 1.1, 2.0 | Switch frame |
| `SW_HEIGHT, SW_BODY_H` | 5.0, 3.0 | Switch total height / body (informational: prints plunger tip vs exterior) |

## History (what tests changed)

1. v1 positions came from photo calibration (±1 mm) — `HOOK_DX` 23.05.
2. Coupon #1: everything was off → shifted **3.5 mm** towards the centre; magnet pockets removed; switch seats added.
3. Coupon #2 request: another **1 mm** towards the centre → current values.

## Open / next

  would stick out; `SW_HEIGHT` prints where the tip lands.
- Button seat is derived, not measured: if the button column is off, change `WALL_TO_BTN` or set `BTN_DX` directly.
